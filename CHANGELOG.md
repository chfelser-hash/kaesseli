# Änderungen

Neueste Version zuoberst. Format: `## Version – Datum`, darunter je eine Zeile pro Änderung.
Die Version steht auch in `package.json` und unter «Mehr → Über Kässeli».

## 1.0.0 – 2026-10-30
- Erste Version mit Versionsnummer – unter «Mehr → Über Kässeli» sieht man, welcher Stand läuft, und die App meldet neue Versionen.
- Neu: «Nach Updates suchen / Jetzt aktualisieren» – neue Versionen ohne SSH einspielen; Kässeli sichert vorher und startet von selbst neu. Zurück zu einer früheren Version ebenfalls möglich.
- Angeboten werden nur Versionen, die auf GitHub alle Tests bestanden haben (automatische Markierung vX.Y.Z).
- Einmalig nötig: Umstellung auf der NAS per SSH (siehe README, «Aktualisieren über die App»).
- Umfang: Erfassen (Jahr/Monat/Abrechnung), «Jetzt abrechnen», Übersicht mit Monitoring und Kategorien inkl. Unterkategorien, Budget mit «Geht das Budget auf?», Sparen als Rest am Zyklusende, Import (CSV und Kreditkarten-Text), Regeln, tägliche Sicherung, automatische Tests.
